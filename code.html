Machines, Built in the Open

A virtual machine is not a black box but a sequence of small, deliberate choices. These repositories make the choices one at a time, where they can be seen: each step is the whole machine again, with one idea more, so that the difference between two steps is the lesson. From a loop in C to compilers, garbage collection, native code and a circuit. The book: Growing a Machine →

Reconstructions

Systems from around 1980, rebuilt from what was published about them rather than copied, so that they can be run again and read all the way down. Their constraints explain their solutions: often it is the architecture, more than the code, that has something to teach. Most of them run in a browser tab.
